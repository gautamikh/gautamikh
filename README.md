### 🧩 Agentic Text-to-SPARQL : Master's Thesis

Developed two LLM workflows using LangGraph: a fixed pipeline and a dynamic orchestrator. Both break natural-language-to-SPARQL generation into specialized, verifiable stages, with checkpointing for resumable execution.

Built a reproducible evaluation pipeline to compare models using precision, recall, F1-score, and query execution metrics on a SLURM GPU cluster.

**Tools:** Python · LangGraph · SPARQL · RDF · Hugging Face · vLLM · SLURM

### 🕸️ Knowledge Graphs & GraphRAG

Built a Neo4j knowledge graph for mechanical engineering data and developed a GraphRAG system combining LLMs with graph-based retrieval.

Created a Streamlit chatbot for interactive access to engineering knowledge, with semantic data modeling using RDF and OWL.

**Tools:** Python · Neo4j · Cypher · LangChain · CrewAI · Streamlit · RDF · OWL

### 📄 GenerAItor : AI-Assisted Document Processing

Contributed to a capstone project with Insiders Technologies, integrating OpenAI APIs for contextual field naming and automated field selection.

Built a guided onboarding experience and integrated frontend features with a Kotlin-based backend.

**Tools:** OpenAI APIs · React · TypeScript · Intro.js · REST APIs · Kotlin

### 🌐 LLM Fine-Tuning for Translation

Fine-tuned BLOOMZ-1B7 for translation using LoRA and prepared synthetic training and evaluation data with Qwen.

Used Hugging Face tools for parameter-efficient fine-tuning, dataset preparation, and quantization.

**Tools:** Hugging Face · PEFT · LoRA · Accelerate · Qwen
